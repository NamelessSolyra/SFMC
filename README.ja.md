## 導入と接続

1. 両方のPCにWindows x64、同じバージョンのMewgenicsとSFMC 1.0.5が必要です。ゲームを終了し、英語版のZIPをそれぞれのMewgenics.exeと同じフォルダーに展開します。
2. 2台のPCを同じLANに接続します。インターネット経由で遊ぶ場合は、Hamachi、Tailscale、Portholeなどで同じ仮想LANに参加してください。
3. 両方のPCでSTART_SFMC.cmdまたはSFMC.exeを起動し、F1でパネルを開きます。ホストは **Host game** を、もう一人は **Join** を選び、ホストのLANまたは仮想LANのIPアドレスを入力します。既定のポートは27600です。戦闘開始前に接続してください。

## 家での操作と冒険

家の操作はホストが担当します。もう一人はホストの画面やイベントシーンを見たり、冒険の準備をしたり、自分の画面で猫の能力を確認したりできます。家を各自のPCから独立して操作する機能は開発中です。

猫を選んだあと、ホストがクラスを割り当て、もう一人が編成を確定します。冒険中はそれぞれが担当の猫を操作します。戦闘やイベントの合間にマップ上で **Co-op** を開くと担当を変更できます。最初からクリアまで一緒に遊べ、帰宅後もゲームを終了せず次の冒険を始められます。

作者による2人プレイのテスト時間は200時間を超えています。まれに不具合やクラッシュ、同期ずれが発生します。同期ずれで戦闘が停止した場合は、両方のゲームを再起動し、共通のチェックポイントを読み込んでください。バックアップ先は saves/SFMC_backups です。リリース版は診断ログを出力しません。
