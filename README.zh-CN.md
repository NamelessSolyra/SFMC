## 下载安装与联机

1. 两台电脑都需要 Windows x64、相同版本的 Mewgenics 和 SFMC 1.0.5。关闭游戏，将英文版压缩包解压到 Mewgenics.exe 所在的文件夹。
2. 两台电脑须在同一局域网内。远程联机可以使用 Hamachi、Tailscale、Porthole 等工具建立虚拟局域网。
3. 双方运行 START_SFMC.cmd 或 SFMC.exe，按 F1 打开面板。房主点击 **Host game**；另一位玩家点击 **Join**，输入房主的局域网或虚拟网络 IP 地址。默认端口为 27600，请在战斗开始前加入。

## 家园与冒险

房主操控家园。另一位玩家可以观看房主画面和过场动画、准备出发，也可以在自己的屏幕上查看猫的属性。双人独立操控家园的功能仍在开发中。

选好猫之后，房主分配职业，另一位玩家确认队伍。冒险中各自操作自己的猫。在战斗和事件之间，可以从地图打开 **Co-op** 面板，更换猫的操控者。你们可以一起从开局玩到通关，回家后无需退出游戏即可开始下一次冒险。

作者进行了超过 200 小时的双人测试。偶尔仍可能出现错误、闪退或不同步。如果战斗因不同步而停止，请双方重新启动游戏，读取共同的检查点。存档备份位于 saves/SFMC_backups，发布版不写入诊断日志。
